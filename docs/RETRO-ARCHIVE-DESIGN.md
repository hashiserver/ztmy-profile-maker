# ライブアーカイブの画面

2026-10-20。ユーザー承認済みの比較モック「1の背景 × 3の窓枠」を実装。

- 暗い紺色のディザ・植物線画の背景に、半透明の青紫のブラウザ窓。
- トップはライブごとの入口。文禍伝雷を開くと、そのライブ用テンプレート一覧の窓が開く。ユーザープロフィールの投稿・一覧機能は設けない。
- 今回の文禍伝雷には @1to_ztmy の提供カード1件。ライブに属さないデモカードは別の入口。
- 一覧窓から既存編集ルートへ移動。編集は同じ窓枠、既存のCanvas・PNG出力・下書き保護を維持。
- スマートフォンでは窓を全幅近くで開き、縦スクロール。戻る・閉じる・Escapeで閉じ、フォーカスは元の入口へ戻す。
- ログイン、投稿、実際の別ブラウザウィンドウ、ドラッグ操作、外部への自動送信は追加しない。
- モック上の仮想URLは現在の位置を示す装飾。ホーム/戻る/閉じるの実操作だけを表示する。
