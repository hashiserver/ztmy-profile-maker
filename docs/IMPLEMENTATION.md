# 初期実装の範囲と確認記録

2026-10-20。対象: `feat/card-editor-foundation`。基準: SPEC v1.8。
**MVP完成ではなく、最初の動作する開発マイルストーン**。

## 実装済み

- Astro静的ページ＋React編集画面、Tailwind CSS v4。API・DBサーバーなし。
- 運営制作デモ1件と、提供画像の許諾申請用確認テンプレート1件。作者未確認の画像を運営制作とは表記しない。
- カード上とフォームから項目選択、日本語入力、改行、共通レイアウト・Canvasによるプレビューと元画像サイズのPNG（デモ1200×1600／提供画像1537×2048）。
- 横書き、自動縮小、はみ出し警告、縦書きの初期実装（2桁数字・英単語・句読点の基本処理）。
- 文字サイズ・色・フォント・横揃え、矢印による1px位置調整と位置リセット。
- 円形アイコン、JPEG/PNG/WebPのブラウザ内正規化、拡大・上下左右のスライダー、差し替え・削除・リセット。
- テンプレートごとのIndexedDB下書き、約700msの遅延保存、自動復元。リビジョン比較、復元前保存防止、互換性不明データの上書き防止、初期化確認。
- Web Share APIとPNGダウンロード代替、画像・文章コピー、X投稿画面へのリンク。
- サービス説明、開発初期版の規約・プライバシーポリシー、フォントライセンス原文。
- PRとmain用GitHub Actions（型・ユニット・ビルド・Chromium・確認画像）。

## 確認する項目

- `npm run check`: エラー0、警告0。
- `npm test`: レイアウトとIndexedDBの9テスト合格。
- `npm run build`: 6ページの静的出力に成功。
- `npm run test:e2e -- --workers=2`: 8テスト合格。テンプレート選択、入力、PNG寸法、復元、未知バージョン保護、画像アップロード、375px幅、IMEイベント、フォント変更後のPNGピクセル一致、読込中の出力抑制、競合通知。
- PCと375pxのスクリーンショットを目視。CI実行時の画像はActions成果物に保存する。

IMEイベントの自動テストは実際のOSキーボードを代替しない。共有先アプリ・iPhone Safari・Androidの実機検証は未実施。

## MVP完了までの残作業

1. Canvas／DOM・SVGでの縦書き比較、禁則・括弧字形・長い欧文・複数フォントを含む組版検証。現方式を最終決定しない。
2. 日本語フォント8〜10種へ拡張。現在はNoto Sans JP／Noto Serif JPの2種を同梱。
3. スマホの下部入力パネル・キーボード表示時のプレビュー、文字ドラッグとスクロールのモード分離、通常4px／詳細1px操作。
4. アイコンのドラッグ・ピンチ。現在のスライダーは代替として先行実装。
5. 先行登録した提供画像の許諾と作者情報を確認。任意の前面装飾レイヤー、テンプレートごとの移動許容範囲・タップ領域も拡張する。
6. テンプレート登録CIの画像参照・寸法検証、座標重畳・通常／長文の確認画像と運営者チェックリスト。
7. 実機テスト、アクセシビリティ監査、画像メモリ負荷、連続操作・複数タブ競合の追加テスト。
8. Cloudflare Pages接続、PRプレビュー無効設定、無料枠の確認、解析・公開前規約確認。

## 開発中の判断

- 既存仕様とREVIEWの「要件変更時のみ再確認」に従い、要件を再開せず実装。MVP要件の削除は行わない。
- 初回は新作オリジナルデモを使用。2026-10-20のユーザー指示により、提供画像を許諾申請用の確認版として先行登録。許諾・作者情報は未確認。
- 新規checkout内の専用ブランチで作業し、mainに直接変更しない。
- フォントを同一オリジンに同梱。UI用ゴシックは初期読込、明朝は使用時読込。Canvas用に入力文字のフォント読込完了を待つ。
- 初期デモの印刷済みラベルを英語にし、OSの日本語フォント有無による背景SVGの出力差を避ける。
- ブラウザテストは127.0.0.1の静的previewサーバーを前景起動する。
- レビューで見つかった画像読込中のPNG保存と、古い保存リビジョンの成功誤表示を回帰テスト付きで修正。
- 画面外Canvasの言語をjaに統一し、明朝・日本語・数字を含むプレビューとPNGのピクセル一致を確認。
